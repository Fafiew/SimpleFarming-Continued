# Simple Farming: Continued

**The same simple farming experience, continued on newer Minecraft versions.**

Simple Farming: Continued is an independent continuation of
[Simple Farming](https://www.curseforge.com/minecraft/mc-mods/simple-farming),
originally created by **enemeez1**. It keeps the original experience alive by
bringing it to newer Minecraft versions and additional mod loaders, while
preserving what made the original mod enjoyable.

- **Downloads:** [CurseForge](https://www.curseforge.com/minecraft/mc-mods/simple-farming-continued) · [Modrinth](https://modrinth.com/mod/simple-farming-continued)
- **Source code:** [1.21.1 branch](https://github.com/Fafiew/SimpleFarming-Continued/tree/1.21.1)
- **Minecraft:** 1.21.1 — Forge, NeoForge, Fabric
